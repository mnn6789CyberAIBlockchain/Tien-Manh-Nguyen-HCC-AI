# AI in Cybersecurity – ITAI 1372

This folder contains my projects from the AI in Cybersecurity course at Houston Community College.

The focus of this course is applying artificial intelligence to real-world security problems, including:

- Prompt Injection Attacks
- AI System Vulnerabilities
- Secure AI Application Design
- OWASP Top 10 for LLM and API Security

## Featured Project

### MyBistro AI (Secure RAG System)

A secure AI assistant built with Retrieval-Augmented Generation (RAG) and integrated security guardrails.

Key features:
- Context-based responses using internal knowledge base
- Prompt injection detection and blocking
- Security logging and monitoring
- Toggleable “Security Shield” for demo purposes

This project demonstrates how AI systems can be both powerful and vulnerable, and how to defend against attacks.
