# Neural Network Foundations (Fashion-MNIST)

## Problem
Learn how basic neural networks can classify image data.

## Approach
Built a neural network model using TensorFlow/Keras to classify clothing images from the Fashion-MNIST dataset.

Steps:
- Load and preprocess dataset
- Build neural network model
- Train and evaluate performance
- Visualize predictions

## Results
- Achieved solid classification accuracy on Fashion-MNIST
- Demonstrated how neural networks learn patterns from image data

## Key Learnings
- Fundamentals of neural networks
- Model training and evaluation
- Overfitting vs generalization

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

## Dataset
Fashion-MNIST dataset  
Loaded using:
`tensorflow.keras.datasets.fashion_mnist`

## Requirements
See `requirements.txt`

## How to Run
Open in Google Colab or Jupyter Notebook and run all cells.
