# CNN Image Classifier (Puppy vs Bagel)

## Problem
Classify visually similar objects (puppies vs bagels) using deep learning.

## Approach
Built a Convolutional Neural Network (CNN) model for binary image classification.

Steps:
- Image preprocessing (resize, normalize)
- Build CNN architecture
- Train and validate model
- Evaluate predictions

## Results
- Model successfully distinguishes between puppies and bagels
- Learned feature extraction using convolution layers

## Key Learnings
- CNN architecture and feature extraction
- Importance of data preprocessing
- Model performance tuning
