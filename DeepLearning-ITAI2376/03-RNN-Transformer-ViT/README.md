# RNN vs Transformer vs Vision Transformer

## Problem
Compare different deep learning models for text and image classification.

## Approach
Implemented and compared:
- RNN
- LSTM
- GRU
- Transformer
- Vision Transformer (ViT)

Tasks:
- Text classification (AG News)
- Image classification (CIFAR-10)

## Results
- Transformers performed better on complex patterns
- Vision Transformers showed strong performance on images
- RNN models effective for sequential data

## Key Learnings
- Differences between RNN and Transformer architectures
- Attention mechanism in Transformers
- Strengths of Vision Transformers

## Technologies Used
- Python
- TensorFlow / Keras
- PyTorch
- NumPy
- Matplotlib

## Dataset
- AG News dataset
- CIFAR-10 dataset

Loaded using built-in libraries (no manual download required)
