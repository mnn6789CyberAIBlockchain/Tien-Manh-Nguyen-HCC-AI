# Diffusion Model for Image Generation

## Problem
Understand how generative AI models create images from noise.

## Approach
Built a basic diffusion model that:
- Adds noise to images (forward process)
- Learns to remove noise (reverse process)

## Results
- Generated simple images from noise
- Visualized step-by-step diffusion process

## Key Learnings
- How diffusion models work
- Generative AI concepts
- Difference between generative and classification models

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
